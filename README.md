# Shopping Mall

멋쟁이사자처럼 14기 동아리 활동 중 제작한 쇼핑몰 프로젝트입니다.

React를 사용해 상품 목록과 상세 페이지를 구현하고,  
API를 연동해 상품 등록, 수정, 삭제 기능을 구현하습니다.

**배포 링크**  
[실제 Netlify 배포 주소 입력
](https://orang-shoppingmall.netlify.app/)
## Tech Stack

- React
- JavaScript
- Vite
- React Router
- Axios
- Styled Components

## 구현 내용

- 상품 목록 조회
- 의류 / 신발 카테고리 분류
- 성별, 색상, 사이즈, 가격대 필터링
- 상품 상세 페이지
- 상품 등록
- 상품 수정
- 상품 삭제
- API를 이용한 상품 데이터 CRUD
- React Router를 이용한 페이지 라우팅

## 공부 내용

- React 컴포넌트 구조
- React Router를 이용한 페이지 이동
- Axios를 이용한 API 통신
- GET, POST, PUT, PATCH, DELETE 요청
- 상태를 이용한 상품 필터링
- API 응답 데이터를 화면에 렌더링하는 방법
- GitHub Issue와 Pull Request를 활용한 협업

## Collaboration

- Issue를 생성한 후 작업 브랜치 생성
- 작업 완료 후 `develop` 브랜치로 Pull Request
- 팀원 리뷰 후 병합
- `main` / `develop` 브랜치를 나누어 관리
